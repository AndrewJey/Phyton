## Ejercicios del curso en Python 3

Los nueve ejercicios históricos de `Python-master/Curso/` se han adaptado a Python 3 y ejecutado con Python 3.12. No requieren paquetes externos. En PyCharm, selecciona un intérprete Python 3.12 para esta carpeta, o ejecuta desde PowerShell:

```powershell
py -3.12 'Python-master/Curso/10Funciones.py'
```

El ejemplo imprime `24`. Esta comprobación corresponde a esos ejercicios, no certifica los otros materiales incluidos en el repositorio.
